# Dota Assistant: всё в одной программе (Windows)

Запуск: дважды нажмите ЗАПУСК.bat (нужен Python с python.org, галочка "Add Python to PATH").
Готовый exe: build_exe.bat на Windows или загрузка папки на GitHub (вкладка Actions -> DotaAssistant-exe).

Вкладки:
- Игра: оверлей с советами каждую секунду, таймеры, чтение миникарты, установка интеграции с Dota 2.
- Статистика: профиль, последние матчи и разбор, тренер, мета героев, инфо о герое.
- Драфт: подсказка пика по вражеским и союзным героям.

Порядок первого запуска: ввести Steam ID и позицию -> "Установить интеграцию с Dota 2" -> перезапустить Dota 2
-> режим "Оконный без рамки" -> (по желанию) настроить миникарту и нажать "Проверить".
Таймеры в timers.json зависят от патча, сверяйте их.
